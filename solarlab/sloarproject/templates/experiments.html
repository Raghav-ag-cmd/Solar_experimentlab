Experiments

Three short experiments that show how conditions change the output of a solar panel.

Why run experiments?

A good experiment changes one thing at a time. Experiment A is the baseline, with the panel facing the sun in clear weather. Experiment B changes only the angle, and Experiment C changes only the weather. Because everything else stays the same, any difference in the output can be blamed on the one thing that changed. Scientists call this a fair test.

Each experiment also starts with a prediction. Write down what you expect before you run it, then compare it with the result. If the result surprises you, that is a good thing to investigate.

Before you start

  1. Open the simulator and set the panel rating to 100 W.
  2. Reset all sliders to their starting values.
  3. Press Save result at the end of each experiment.
Experiment A

Direct sunlight

Question: How much power does a panel make when it faces the sun?

  1. Set weather to sunny and intensity to 100%.
  2. Set the angle so the panel faces the sun (θ = 0°).
  3. Record the output.

Expected: the highest output of the three.

Experiment B

Oblique sunlight

Question: What happens when the panel is tilted away?

  1. Keep weather sunny and intensity at 100%.
  2. Tilt the panel so θ = 60°.
  3. Record the output.

Expected: about half of Experiment A, because cos(60°) = 0.5.

Experiment C

Cloudy conditions

Question: How much do clouds reduce the output?

  1. Set weather to cloudy.
  2. Set θ = 0° so only the weather changes.
  3. Record the output.

Expected: far lower than Experiment A, even with a perfect angle.

How results are saved

In Experiment mode, each run is stored in the browser's local storage on the laptop. When the results table is shown, JavaScript reads the saved runs, works out how many times larger or smaller one output is than another, and writes a sentence such as "Experiment A produced twice the output of Experiment B". No data is sent over the internet.

Project status: the pages, the light and dark themes and the phone menu are finished. The simulator, graphs and saved experiment results are being built in stages.

What to conclude

Compare A with B to see the effect of angle, and A with C to see the effect of weather. Write one sentence for each in your own words.
