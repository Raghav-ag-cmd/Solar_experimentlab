Features

Everything you can change, compare and record in Solar Lab.

This page lists what Solar Lab lets you do, and under each feature it explains how it is built. Most features follow the same pattern: a control in HTML, a JavaScript function that reads it, and a drawing or number that updates on the screen.

Each feature is added one at a time and tested before the next one, so any problem can be traced to a single step. Press Try it in the simulator on any card to open the simulator with that feature highlighted.

Project status: the pages, the light and dark themes, the phone menu, the simulator, the graphs and the saved experiment results are all working.

Panel angle control

A slider tilts the panel from 0° to 90°. The drawing and the output update as you move it.

How it is built: A range slider in HTML. JavaScript reads its value every time it moves, redraws the panel on a canvas and recalculates the power.

Try it in the simulator →

Sunlight intensity

Set the strength of the sunlight from 0 to 100% to see how a dimmer sun affects power.

How it is built: A second slider whose value, from 0 to 1, becomes the I in the formula.

Try it in the simulator →

Weather conditions

Choose sunny, partly cloudy or cloudy. Each condition applies a different factor to the sunlight.

How it is built: A drop-down menu. Each choice is linked to a number that multiplies the sunlight intensity.

Try it in the simulator →

Shading

Add shade over the panel and see how much output is lost.

How it is built: A slider for the percentage of shade. The code multiplies the power by what is left after the shade is removed.

Try it in the simulator →

Two-panel comparison

Set up Panel A and Panel B differently and see both outputs and the percentage difference.

How it is built: The same calculation function runs twice, once for each panel, with separate settings. The page then works out the percentage difference.

Try it in the simulator →

Live graph

A graph follows the estimated output over time as you change the settings.

How it is built: A canvas drawing. JavaScript keeps a list of recent output values and draws a line through them.

Try it in the simulator →

Best-angle curve

A second graph plots output against angle, so you can see the cosine shape and where the peak is.

How it is built: A loop calculates the power at every angle from 0° to 90° and plots the results as a curve. The highest point is the best angle.

Try it in the simulator →

Experiment mode

Run guided experiments, save the results in your browser and get an automatic comparison. See the experiments page.

How it is built: Buttons set the controls to preset values. Each result is saved as a small record in the browser's local storage, and the page writes the comparison.

Try it in the simulator →

Lambert's cosine law

The power calculation follows Lambert's cosine law: the light a surface receives depends on the cosine of the angle at which it strikes.

How it is built: one JavaScript function converts the angle to radians and multiplies the rated power by its cosine.

Try it in the simulator →

Bar graphs

Bar charts on the simulator compare Panel A with Panel B and show the output of both at every tilt. The home page shows the cosine law and the effect of the weather.

How it is built: each chart is drawn on a canvas with a loop. A bar's height is its value divided by the maximum, times the height of the chart.

Try it in the simulator →

Colour styles

Choose a colour style inspired by well-known websites. The whole site and the simulator scene change together.

How it is built: each style is a set of CSS colour variables. Picking one changes a setting on the page, and the choice is remembered in local storage.

Try it in the simulator →

Light and dark themes

Switch the whole site between light and dark. Your choice is remembered.

How it is built: CSS colour variables and a theme setting on the page, switched by JavaScript and remembered in local storage.

Try it in the simulator →

Works offline on any screen

No internet is needed, and the layout adjusts to laptops, tablets and phones.

How it is built: A Flask program runs on the laptop, and CSS media queries change the layout for phones, tablets and laptops.
