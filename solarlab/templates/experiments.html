Experiments

Three short experiments that show how conditions change the output of a solar panel.

Why run experiments?

A good experiment changes one thing at a time. Experiment A is the baseline, with the panel facing the sun in clear weather. Experiment B changes only the angle, and Experiment C changes only the weather. Because everything else stays the same, any difference in the output can be blamed on the one thing that changed. Scientists call this a fair test.

Each experiment also starts with a prediction. Write down what you expect before you run it, then compare it with the result. If the result surprises you, that is a good thing to investigate.

Before you start

  1. Open the simulator and scroll to Experiment mode.
  2. Press Run on an experiment. It sets the sun, angle and weather for you.
  3. Press Save result. The results table fills in by itself.
Experiment A

Direct sunlight

Question: How much power does a panel make when it faces the sun?

  1. Set weather to sunny. Press Run, which gives the lab test full-strength sunlight with the sun at 30°.
  2. Set the angle so the panel faces the sun (θ = 0°).
  3. Record the output.

Expected: the highest output of the three.

Experiment B

Oblique sunlight

Question: What happens when the panel is tilted away?

  1. Keep weather sunny and the sunlight at full strength.
  2. Tilt the panel so θ = 60°.
  3. Record the output.

Expected: about half of Experiment A, because cos(60°) = 0.5.

Experiment C

Cloudy conditions

Question: How much do clouds reduce the output?

  1. Set weather to cloudy.
  2. Set θ = 0° so only the weather changes.
  3. Record the output.

Expected: far lower than Experiment A, even with a perfect angle.

Output and Angle Comparison

The table below shows the measured power output for each experimental condition:

Experiment Angle θ Weather Output (W)
A 0° Sunny 50 W
B 60° Sunny 25 W
C 0° Cloudy 15 W

What to conclude

Effect of angle (A vs. B): Experiment A (0°) produced twice the output of Experiment B (60°), demonstrating that a more direct angle to the sun significantly increases solar energy capture.

Effect of weather (A vs. C): Experiment A (Sunny) produced over three times the output of Experiment C (Cloudy), showing that cloud cover drastically reduces the panel's power generation due to lower light intensity.
