About Solar Lab

An interactive simulator that shows how the angle of sunlight changes the power a solar panel produces.

What it is

Solar Lab is a web-based simulator. Visitors change the tilt of a solar panel, the strength of the sunlight and the weather, then see the estimated electricity output change straight away.

The idea is simple: instead of telling people that the angle of a panel matters, let them move it and see the result. Each change to a slider updates the picture and the power number at once, so the cause and the effect sit side by side.

The project also shows how a scientific model works. A formula is turned into code, the code is tested against numbers we can check by hand, and the results are compared with what we expect.

At its heart is Lambert's cosine law, which says the light a surface receives is proportional to the cosine of the angle between the light and the surface's normal. Solar Lab turns that law into code and shows the results as a live scene and bar graphs.

Why I made it

My project is an interactive digital model that simulates how solar energy generation changes throughout the day based on the sun's position and the panel's tilt angle.

Who it is for

  • Students learning how light and energy are related.
  • Visitors who want to try experiments without any equipment.
  • Anyone curious about why panels are tilted.

How it is built

Technology Used for
HTML Page structure
CSS Layout, light and dark themes, phone support
JavaScript Scientific calculations and controls
Canvas Panel animation and live graphs
Local storage Saving experiment results in the browser
Python (Flask) Sending each page to the browser

The website is split into seven pages. Every page uses the same header, menu and footer, so it looks like one project. The layout is written for phones first and then adjusted for tablets and laptops, which is why the menu turns into a button on a small screen.

The light and dark themes use colour variables in the CSS. A small piece of JavaScript changes one setting on the page when the theme button is pressed, and the browser remembers the choice for the next visit.

A short Python program using Flask sends the pages to the browser. It needs no database and no extra hardware, so the project can run on a laptop or be put online with a hosting service.

Solar Lab is a simplified educational model. Real panels also depend on temperature, shading, dust and electrical losses.
